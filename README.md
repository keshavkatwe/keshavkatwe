## What I’m building

### [Agenvik](https://github.com/keshavkatwe/agenvik)

An open-source platform for AI agents grounded in your own knowledge. Bring documents, configure agent behavior, and connect conversations across web, WhatsApp, and Slack.

- Knowledge retrieval, durable conversation state, and organization-scoped context.
- A React dashboard with a TypeScript backend, LangGraph, Bun, PostgreSQL, and pgvector.
- Available under the **MIT license**.

[Source code](https://github.com/keshavkatwe/agenvik) · [Live product](https://agenvik.com) · [Engineering story](https://keshavkatwe.github.io/work/agenvik/)

### [Pushwing](https://pushwing.com)

AI-connected publishing workflows for YouTube and Instagram, with a React dashboard, API, and hosted MCP server.

- Shared services connect the dashboard and AI-client workflows.
- Background jobs, OAuth connections, and activity views support the publishing process.
- Built with TypeScript, React, Bun, Elysia, and PostgreSQL.

[Visit Pushwing](https://pushwing.com) · [Engineering story](https://keshavkatwe.github.io/work/pushwing/)

### [Toolgrain](https://github.com/keshavkatwe/toolgrain)

A TypeScript toolkit for building MCP servers from typed, reusable tools.

- Define tools once with Zod input and output validation, then compose them into servers.
- Share request-scoped context across tools and serve over stdio or HTTP.
- Optional JWT and Clerk authentication, with framework examples and an **MIT license**.

[Source code](https://github.com/keshavkatwe/toolgrain) · [npm package](https://www.npmjs.com/package/@toolgrain/mcp) · [Documentation](https://github.com/keshavkatwe/toolgrain/tree/main/docs) · [Engineering story](https://keshavkatwe.github.io/work/toolgrain/)
